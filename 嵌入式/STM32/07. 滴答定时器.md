# 一、滴答定时器简介
## 1. 基本概念 
- Svstick定时器属于内核定时器，是一个简单的定时器，对于CM3、CM4内核芯片都有这个定时器
- Systick定时器常用来做延时，或者实时系统的心跳时钟。这样可以节省MCU资源，不用浪费一个定时器
## 2. 系统定时原理
- Systick定时器就是系统滴签定器个24 位的倒计数定时器，计到0时，将从RELOAD 寄存器中自动重装载定时初值。只要不把它在SvsTick控制及状态寄存器中的使能位清除，就永不停息，即使在睡眠模式下也能工作。主要用于：
	- 精确延时：实现毫秒（ms）、微秒（μs）级延时。
	- 定时中断：例如每隔 1 ms 触发一次中断。
	- 系统计时：为操作系统或 HAL 库提供时间基准。
- Systick定时器是捆绑在NVIC当中，用于产生SYSTICK异常（异常号：15）。
## 3. SysTick 的四个重要寄存器
### SysTick->CTRL 控制和状态寄存器
- 用来控制定时器的运行
- **Bit0**：ENABLE,当该位设置为1时启动计数，设置为0时停止计数。
- **Bit1**：TICKINT,设置为1时允许滴答定时器产生中断请求
- **Bit2**：CLKSOURCE，选择计数器的时钟来源，0为外部时钟源，1为内核时钟
- **Bit16**：CUNTFLAG，记录计数器是否到过0，如果上次读取后已经数到了0，则该位为1，如果读取该位则该位自动清零
### SysTick->LOAD重装载值寄存器
- 用于设置计数器的计数周期
- 当倒数至零时。将被重装载的值，对于周期性计数，重装载值需要设置为N-1，N是一个周期需要的时钟周期数
### SysTick->VAL当前计数值寄存器
- 用于记录档前计数值
- 读取时返回当前计数的值，写它则使之清零，同时还会清除控制状态寄存器中的COUNTFLAG标志
### SysTick->CALIB校准值计数器
- 是一个只读寄存器，用来提供定时器的时钟校准信息
- **Bit31**：NOREF，为1则代表没有外部参考时钟，为零则是指外部参考时钟可用
- **Bit30**：SKEW，为1则校准值不是准确的10ms,为0则校准值是准确的10ms
- **Bit23:0**：TENMS，10ms内倒计数的格数。如果该值读回0，则表示无法使用校准功能
## 4. SysTick相关函数
 - **SysTick_ClkSoureConfig(uint32_t SysTick_CLKSource)**
	 - 函数作用：对系统时钟进行分频
	 - 参数说明：可以选择两个参数八分频和一分频
	 - 函数出处：misc.c
- **__STATIC_INLINE uint32_t SysTick_Config(uint32_t ticks)**
	- 函数作用：配置系统时钟，开启系统中断
	- 函数返回值：0表示成功，1表示设置数值超过最大值，设置失败
	- 函数参数：代表两个ticks之前的中断节拍数
- **oid SysTick_Handler(void)**
	- 函数作用：当系统定时器开启了中断，并开始计数，每次计数完成都会调用该中断服务函数

- 使用中断方式则直接调用SysTick_Config函数，传入一个数值，系统就能根据这个计数值开启计数，并且产生中断
