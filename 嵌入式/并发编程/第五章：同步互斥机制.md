# 01.互斥锁与读写锁
## 基本概念
- 互斥是指控制两个进程是指相互排斥，不同时运行
- 同步是指控制两个进度使之有先有后，次序可控
## 互斥锁
### 基本逻辑
- 是使得多线程之间互斥运行的最简单的方法
- 互斥锁的本质是一个二值信号量，因此当其中一个线程获取之后其余线程就无法再次获取，效果相当于给相关的资源上了锁，直到使用者主动解锁，其它线程才有机会获得
### 函数接口
- **定义**：
	- pthread_mutex_t m;
	- 由于互斥锁要被多条线程使用，因此一般会定义为全局变量
- **初始化与销毁**：
	- 未经初始化的互斥锁无法使用
	- 静态初始化：定义同时赋予其初始值
	- 动态初始化：使用pthread_mutex_init()，给互斥锁分配动态内存并赋予初始值，这种情形下的互斥锁在使用完后需要显示的释放资源
	- 静态初始化互斥锁不涉及动态内存，不需要显示释放互斥锁资源
	- 
		// 初始化互斥锁
		int pthread_mutex_init(pthread_mutex_t \*restrict mutex,
		                       const pthread_mutexattr_t \*restrict attr);
		
		// 销毁互斥锁
		int pthread_mutex_destroy(pthread_mutex_t \*mutex);
	- 接口说明：
		- mutex：互斥锁
		- attr：互斥锁属性
- **加锁与解锁**：
	- 加锁：pthread_mutex_lock(&m);
	- 解锁：pthread_mutex_unlock(&m);
