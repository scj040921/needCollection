#  01.进程与程序
## 基本概念
- **程序**：编译后产生的，格式为ELF的，存储与硬盘的文件
- **进程**：程序中的代码和数据，被加载到内存中运行的过程
- 程序是静态的概念，进程是动态的概念
- 在Linux中程序文件的格式都是ELF，这些文件在被执行的瞬间，就被载入内存，就是将数据段、代码段等运行时必要的资源拷贝到内存，另外系统会分配相应的栈、堆等内存空间给这个进程，使之成为一个动态的实体。
## 进程的组织方式
- 在Linux中除系统的初始进程外，其余所有进程都是通过一个父进程复刻（fork）而来的，因此在整个Linux系统中所有进程都起源于相同的初始进程。
- 最开始的系统进程叫systemd，其身份信息在系统启动前就已经存在于系统分区，在系统启动时直接复制到内存。
## 进程的复刻（fork)
- 除系统的初始进程之外，其它的所有进程都是通过fork()复刻而来的。
- 一个父进程复刻一个子进程时，会将自身所有资源复制一份
	- **一样的有**：
		1. 实际UID和GID，以及有效UID和GID
		2. 所有环境变量
		3. 进程组ID和会话ID
		4. 当前工作路径
		5. 打开的文件
		6. 信号相应函数
		7. 整个内存空间，包括栈、堆、数据段、代码段、标准IO的缓冲区等
	- **不同**：
		1. 进程号PID
		2. 记录锁，子进程不会获得父进程对某一文件加的锁
		3. 挂起的信号
## 进程的状态
- 所有进程都有一个父进程
- 父进程复刻自身得到一个子进程
- 新创建的子进程拥有于父进程一样的执行代码、内存空间等信息，并处于就绪状态
- 当进程退出时，不论是否是主动退出，进入僵尸态，僵尸态下进程无法运行，也无法被调度，但其所占用的系统资源还没有释放。僵尸状态是进程的必经状态，编程过程既不能避免僵尸状态但要避免长时间处于僵尸状态。
- 僵尸态进程要等待其父进程对其进行资源回收后才能变成死亡态，死亡态的进程所占据的系统资源可以随时被系统回收
