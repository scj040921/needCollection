# 网络编程进阶

> [!abstract] 学习顺序
> 先建立“字节如何从一个进程到另一个进程”的全貌，再分别掌握 TCP、UDP、事件循环与 HTTP。每一层都要能说明：**协议边界、阻塞点、失败处理、资源释放**。

1. [[01-网络基础与TCP]]：地址、字节序、TCP 生命周期和 socket 选项；
2. [[02-UDP与套接字实践]]：数据报通信与可观测性；
3. [[03-多路复用与云服务器]]：`select/poll/epoll`、部署连通性；
4. [[04-HTTP与JSON]]：应用协议、解析和设备上报。

## 一张调用链

```text
应用消息 → 编码（长度/JSON） → send/recv 或 sendto/recvfrom
         → TCP/UDP → IP → 网卡 → 网络 → 对端按相反顺序解码
```

> [!warning] 贯穿所有笔记的三条规则
> TCP 是**无消息边界的字节流**；`read/write/recv/send` 都可能短传输；任何来自网络的长度、字段和字符串都不可信。
