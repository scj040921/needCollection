# 1. 栈
## 基本概念
- 只能在固定的一端操作，是一种特殊的线性表
- 符合先进后出的逻辑
- 术语：
	- **栈顶**：可进行插入和删除的一端
	- **栈底**：栈顶的对端
	- **入栈**：将节点插入栈顶之上，push
	- **出栈**：将节点从栈顶剔除，pop
	- **取栈顶**：取得栈顶元素但不出栈，top
## 存储形式
栈只是一种数据逻辑，在内存中的存储也有不同的形式，通常有顺序存储形成顺序栈或链式存储形成链式栈
- **顺序栈**:
	- 开辟一块连续的内存来存储数据节点
	- 管理栈数据除了一块连续的内存之外还需要记录栈的总容量、当前栈的元素个数、当前栈顶元素位置
	- 有多线程时还需要配互斥锁和信号量等信息
	- 各种信息存放在一个管理结构体中
- **链式栈**：
	- 组织形式与链表相同
	- 插入和删除操作固定在一端
	- 通过管理结构体存储栈顶指针、栈元素个数等信息
## 基本操作
- **顺序栈**：
	- 顺序栈管理结构体：
	```
	typedef struct 
	{
	    datatype *data; // 顺序栈入口
	    int size;       // 顺序栈总容量
	    int top;        // 顺序栈栈顶元素下标
	}seqStack;
	```
	- 初始化空栈
	```
	seqStack *initStack(int size)
	{
	    seqStack *s = (seqStack *)malloc(sizeof(seqStack))
	    if(s != NULL)
	    {
	        s->data = (datatype *)malloc(sizeof(datatype) * size));
	        if(s->data == NULL)
	        {
	            free(s);
	            return NULL;
	        }
	        s->size = size;
	        s->top  = -1;
	    }
	    return s;
	}
	```
	- 判断栈是否已满
	```
		bool  isFull(seqStack *s)
		{
			return s->top==size-1;
		}
	```
	- 判断栈是否为空
	```
		bool isEmpty(seqStack *s)
		{
			return top==-1;
		}
	```
	- 入栈
	```
		bool push(seqStack *s,datatype data)
		{
			if(isFull(s))
			{
				return false;
			}
			s->data[++s->top]=data;
			return true;
		}
	```
	- 出栈
	```
		bool pop(seqStack *s,datatype *pm)
		{
			if(top(s,pm)==false)
				return false;
			s->top--;
			return true;
		}
	```
	- 取栈顶元素
```
	bool top(seqStac *s,datatype *pm)
	{
		if(isEmpty(s))
			return false;
		*pm=s->data[s->top];
		return true;
	}
```
- **链式栈**
	- 链式栈节点：
	```
		typedef struct node
		{
			datatype data;
			struct node *next;
		}node;
	```
	- 创建链式栈管理结构体
	```
		typedef struct linkStack
		{
			node *top;
			int size;
		}linkStack;
	```
	- 初始化空栈
	```
		linkStack *initStack()
		{
			linkStack *s=(linkStack *)malloc(sizeof(linkStack));
			if(s!=NULL)
			{
				s->top=NULL;
				int size=0;
			}
			return s;
		}
	```
	- 判断栈是否为空
	```
		bool isEmpty(linkStack *s)
		{
			return s->size==0;
		}
	```
	- 入栈
	```
		bool push(linkStack *s,datatype data)
		{
			node *new =(node*)malloc(sizeof(node));
			if(new==NULL)
				return false;
			new->data=data;
			new->next=s->top;
			s->top=new;
			s->size++;
			return true;
		}
	```
	- 出栈
	```
		bool pop(linkStack *s,datatype *pm)
		{
			if(isEmpty(s))
				return false;
			linkStack *tmp=s->top;
			s->top=tmp->next;
			tmp->next=NULL;
			*pm=tmp->data;
			free(tmp);
			return true;
		}
	```
	- 取栈顶元素
```
	bool top(linkStack *s,datatype *pm)
	{
		if(isEmpty(s))
			return false;
		*pm=s->top->data;
		return true;
	}
```
# 2.队列
## 基本概念
- 队列是一种逻辑结构，是一种特殊的线性表，只能在固定的两端操作线性表
- 队列一般呈现出先进先出的逻辑
- 术语：
	- 队头：可以删除节点的一端
	- 队尾：可以插入节点的一端
	- 入队：将节点插入到队尾之后，enQueue
	- 出队：将队头节点从队列中剔除，putQueue
	- 取队头：取得队头元素但不出队，front
## 顺序存储的队列：循环队列
- 队列可以采用顺序存储形成循环队列，也可以采用链式存储形成链式队列
- 循环队列可以通过更新队头队尾的下标信息来循环的运用整个数组，出队入队时也不需要移动当中的数据
- 当front和rear相等时队列为空
- 当rear循环加一与front星等时队列为满
- 管理循环队列除了需要一块连续的内存之外，还需要记录队列的总容量、当前队列的元素个数、当前队头、队尾元素位置、互斥锁和信号量等信息
- 管理结构体：
	```
	struct seqQueue
	{
	    datatype *data; // 循环队列入口
	    int capacity;   // 循环队列总容量
	    int front;      // 循环队列队头元素下标
	    int rear;       // 循环队列队尾元素下标
	};
	```
- **队列的基本操作**
	- 初始化空队列
	```
	seqQueue * initQueue(int cap)
	{
		*pq = (sequeue *)malloc(sizeof(sequeue));
		(*pq)->front = (*pq)->rear = MAXSIZE - 1;
	}
	```
	- 判断队列是否为空
	```
	bool isEmpty(seqQueue *q)
	{
		return q->front == q->rear;
	}
	```
	- 判断队列是否已满
	```
	bool isFull(seqQueue *q)
	{
		return (q->rear+1)%q->capacity == q->front;
	}
	```
	- 出队
	```
	bool outQueue(seqQueue *q, datatype *pm)
	{
		if(isEmpty(q))
			return false;
	
		*pm = q->data[q->front];
		q->front = (q->front + 1) % q->capacity;
	
		return true;
	}
	```
	- 入队
	```
	bool enQueue(seqQueue *q, datatype data)
	{
		if(isFull(q))	
			return false;
		q->data[q->rear] = data;
		q->rear = (q->rear + 1) % q->capacity;
	
		return true;
	}
	```
