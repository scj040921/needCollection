# 1.文件属性
## 获取文件属性信息的函数接口
- **功能**：获取文件的元数据
- **原型**：
	- int stat(const char \*path,struct stat \*buf);
	- int fstat(int fd,struct stat \*buf);
	- int lstat(const char \*path,struct stat \*buf);
- **参数**：
	- path：文件路径
	- fd：文件描述符
	- buf：属性结构体
- **返回值**：
	- 成功：0；
	- 失败：NULL
- **关键点**：
	- stat针对文件名获取其信息
	- fstat针对文件描述符获取其信息
	- lstat可以获取软连接文件本身的属性
	- 这些函数获取了文件属性之后，会将这些信息存入一个称为stat的结构体中
## 文件的设备号
-  Linux系统为了方便管理，为每一种设备分配了主次设备号，主设备号用来规范设备的类型；次设备号用来规范该种设备再本系统中的序号。
- 设备号时系统资源在设备被加载的时候分配完毕
- unsigned int major(dev_t dev);从dev中获取主设备号
- unsigned int minor(dev_t dev);从dev中获取次设备号
