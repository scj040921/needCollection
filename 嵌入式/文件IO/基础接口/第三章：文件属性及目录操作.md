# 1.文件属性
## 获取文件属性信息的函数接口
- **功能**：获取文件的元数据
- **原型**：
	- int stat(const char \*path,struct stat \*buf);
	- int fstat(int fd,struct stat \*buf);
	- int lstat(const char \*path,struct stat \*buf);
- **参数**：
	- path：文件路径
	- fd：文件描述符
	- buf：属性结构体
- **返回值**：
	- 成功：0；
	- 失败：NULL
- **关键点**：
	- stat针对文件名获取其信息
	- fstat针对文件描述符获取其信息
	- lstat可以获取软连接文件本身的属性
	- 这些函数获取了文件属性之后，会将这些信息存入一个称为stat的结构体中
## 文件的设备号
-  Linux系统为了方便管理，为每一种设备分配了主次设备号，主设备号用来规范设备的类型；次设备号用来规范该种设备再本系统中的序号。
```
struct stat
{
     dev_t     st_dev;    // 本文件所在的设备的设备号，适用于非设备文件
     ino_t     st_ino;    // i节点号，相当于身份证号码
     mode_t    st_mode;   // 文件类型 + 文件权限
     nlink_t   st_nlink;  // 文件的别名的数目
     uid_t     st_uid;    // 文件所有者ID
     gid_t     st_gid;    // 文件所在组ID
     dev_t     st_rdev;   // 本文件的设备号，适用于特殊设备文件   
     off_t     st_size;   // 文件大小
     blksize_t st_blksize;   
     blkcnt_t  st_blocks;   
 
     // 文件时间戳
     struct timespec st_atim;  // 最近访问时间，比如打开看一下文件的时间
     struct timespec st_mtim;  // 最近修改时间，比如打开并改一下的时间
     struct timespec st_ctim;  // 最近状态改变时间，比如修改了文件的权限的时间
 }；
```
- 设备号时系统资源在设备被加载的时候分配完毕
- unsigned int major(dev_t dev);从dev中获取主设备号
- unsigned int minor(dev_t dev);从dev中获取次设备号
- **在结构体stat中有两个类型为dev_t的成员。他们分别代表**：
	- 本文件所在设备的设备号，适用于非设备文件（st_dev）
	- 本文件的设备号，适用于特殊设备文件（st_rdev）
	- 特殊设备文件只有设备号的属性，没有文件大小的属性，即st_size是无效的
- **关键点**：
	- 非设备文件一定是存储在某个存储器上的，此时该文件的st_dev代表的是其所在的存储器的设备号。比如某个硬盘
	- 特殊设备文件指的是类型为字符设备或块设备的文件，比如键盘鼠标、硬盘显示器等
	- 特殊设备文件的st_dev成员是无效的，只有st_rdev有效
## 类型与权限
- 在结构体stat中，文件的类型和权限并没有分开存储，而是统一存储到同一个成员st_mode中
- **关键点**：
	- st_mode是一个16位的short短整型数据
	- 前四位表达文件的类型
	- 中间三位分别是set_uid,setgid和stickyBit
	- 后九位表达文件的权限，与三组权限一一对应
- **文件类型判断宏**：
```
S_ISREG(st_mode)  is it a regular file?
S_ISDIR(st_mode)  directory?
S_ISCHR(st_mode)  character device?
S_ISBLK(st_mode)  block device?
S_ISFIFO(st_mode) FIFO (named pipe)?
S_ISLNK(st_mode)  symbolic link?  (Not in POSIX.1-1996.)
S_ISSOCK(st_mode) socket?  (Not in POSIX.1-1996.)
```
- setuid、setgid（只对普通文件有效）与stickyBit（指针对目录有效）
- **作用解析**：
	- setuid：使文件的使用者获得文件所有者的临时授权
	- setgid：使文件的使用者获得文件所在目录的所属组的临时授权
	- stickyBit：使用户只能增加和删除属于自身的文件，不能删除别的用户的文件
# 2. 目录操作
## 基本概念
- 目录是一种特殊的文件，目录存储的数据的最小单位是目录项
- **目录要点**：
	- 整个分区被分成两部分，一部分称为i节点域，另一部分称为数据域
		- i节点域记录的是整个分区的基本信息，包括分区可用空间和已用空间的管理信息
		- 数据域存储文件实际内容数据
	- 每一个文件拥有一个唯一的标识，称为i节点号，分区使用i节点号管理并索引所有的文件，i节点号是分区内部信息，不可以跨分区
	- 目录所存储的数据单元是目录项，目录项指的是结构体struct dirent{}，其内部保存的是文件的名称、i节点号等基本信息，不包含文件具体内容
	- 任何一个目录至少包含两个目录项.和..
		- .代表当前目录..代表上一级目录
		- 如果本目录就是根目录，那么..也代表本级目录
## 创建删除目录
- **创建目录**：
	- **功能**：创建空目录
	- **原型**：int mkdir(const char \*path,mode_t mode)
	- **参数**：
		- path：新创建的目录名
		- mode：新建目录的权限，八进制
	- **返回值**：
		- 成功：0
		- 失败：-1
- **删除目录**：
	- **原型**：
		- 专用于删除空目录：int rmdir(const char \*pathname);
		- 专用于删除文件：int unlink(const char \*pathname);
		- 用于删除空目录或者文件：int remove(const char \*pathname);
	- **参数**：待删除的空目录或文件的名字
	- **返回值**：
		- 成功：0
		- 失败：-1
