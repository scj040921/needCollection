# 1.库相关的基本概念
## 编译过程
- 编译一般会经历如下四个步骤：
	1. 预处理：解释并展开源程序中的所有预处理指令，生成.i文件
	2. 编译：词法和语法的分析，生成对应硬件平台的汇编语言文件，生成.s文件
	3. 汇编：将汇编语言文件，翻译为对应处理器的二进制机器码，此时生成.o文件
	4. 链接：将多个.o文件合并成一个不带后缀的可执行文件
## ELF格式
### 概述
- 在链接这一步时，合并之前的.o文件是ELF格式，合并后也是ELF格式
- ELF的全称是可执行可链接格式，由多个不同的段组成
- ELF格式的合并，实际上就是将多个文件中各自对应的段合并在一起，形成一个统一的ELF文件。
- 在合并的过程中需要对.o文件中的静态数据、函数入口的地址做统一分配和管理，这个过程叫做重定位，因此未链接的.o文件也被称为可重定位文件，经过合并相同段的文件是可执行文件
- 库的本义是图书馆，库文件就是一个由很多.o文件堆积起来的集合
### 相关命令
- readelf可以用来查看ELF格式文件的具体细节
```
# 查看文件格式头部信息
gec@ubuntu:~$ readelf -h a.out

# 查看各个section信息
gec@ubuntu:~$ readelf -S a.out

# 查看符号表
gec@ubuntu:~$ readelf -s a.out
```
- ldd可以用来查看ELF格式文件的动态库依赖关系
```
gec@ubuntu:~$ ldd a.out
```
## 库的基本概念
- 库文件分为两类：静态库和动态库
	- 静态库：libx.a
	- 动态库：liby.so
- 库文件的命名遵循这样的规范：
	- lib库名.后缀
- lib是任何库文件都必须要有的前缀，库名是库文件真正的名称
- 静态库后缀：.a（archive,意思是档案）
- 动态库后缀：.so（share object,共享对象）
# 2.静态库的制作与应用
## 静态库的制作
- **步骤**：
	1. 制作.o原料
	```
	gec@ubuntu:~$ gcc a.c -o a.o -c
	gec@ubuntu:~$ gcc b.c -o b.o -c
	```
	2. 将.o文件合并成一个静态库
		```
	gec@ubuntu:~$ ar crs libx.a a.o b.o
	```
