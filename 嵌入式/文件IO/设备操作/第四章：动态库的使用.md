# 1. 动态库参数优化
## 动态加载库
- 动态库最大的优点，是将链接推迟到运行时，由于运行时才链接动态库，这就给链接的目标留下了选择空间，可以让程序在运行的时候为其指定要连接的动态库，实现按需动态加载
- 具体做法如下：
	- 约定好函数接口
	- 将各个不同需求的实现代码封装到不同的库中
	- 编写相应的配置文件，指定程序在启动后要链接的具体的库
## 相关API
### 打开、关闭动态库
- **原型**：
	- void \*dlopen(const char \*filename,int flags);
	- int dlclose(void \*handle);
- **参数**
	- filename：动态库名称
	- flags：
		- RTLD_LAZY：动态库中的符号被调用时才解析
		- RTLD_NOW：动态库中的符号立即被解析
	- handle：由dlopen返回的动态库操作句柄
- **返回值**：
	- 成功：
		- dlopen：非空的状态库操作句柄
		- dlclose：0
	- 失败：
		- dlopen：NULL
		- dlclose：非空
- **关键点**：
	- RTLD_LAZY意味着打开动态库时，并不立即解析库中的函数符号的内存位置，而是等待程序实际调用时才临时去解析。
	- RTLD_NOW与上述含义相反，它意味着打开动态库时就立即解析库中的函数符号的内存位置。
	- 不管是LAZY还是NOW，库中的静态数据符号都将被立即解析。
