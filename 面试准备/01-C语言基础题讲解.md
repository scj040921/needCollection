## 二、选择题逐题讲解

### 1. C 语言中主函数的名称是什么

**答案：A，`main`。**

程序通常从 `main` 函数开始执行。C 语言区分大小写，因此 `Main`、`MAIN` 都不是标准意义上的同一个函数名。

```c
int main(void)
{
    return 0;
}
```

**面试要点：** `main` 是程序入口；常见返回类型是 `int`；`return 0` 表示程序正常结束的约定。

### 2. 哪个不能作为 C 语言变量名

**答案：C，`123abc`。**

标识符只能由字母、数字和下划线组成，但**不能以数字开头**，也不能使用关键字。`num`、`_age`、`stu_name` 都符合基本命名规则。

**记忆：** “能用字母或下划线开头，后面才可以出现数字；不能撞关键字。”

### 3. C 语言基本数据类型不包括什么

**答案：D，`string`。**

C 语言没有内置字符串类型。字符串通常用 `char` 数组表示，并以空字符 `\\0` 结尾：

```c
char name[] = "abc";
```

常见基本类型包括 `char`、`int`、`float`、`double` 等。

### 4. `int x=3,y=2; printf("%d",x+y);` 输出什么

**答案：B，5。**

`x` 和 `y` 都是整数，使用加法运算后得到 `3 + 2 = 5`，`%d` 用于输出整数。

### 5. `if` 条件表达式为真时，数值是什么

**答案：A，非 0。**

C 语言中，条件表达式的值为 `0` 表示假，**任意非 0 值表示真**。因此不能机械地把“真”理解为只能等于 1。

```c
if (5) {       // 真
}
if (-3) {      // 也是真
}
if (0) {       // 假
}
```

### 6. 自增运算

```c
int a = 10;
if (a > 5)
    a++;
printf("%d", a);
```

**答案：B，11。** `a > 5` 成立，执行 `a++`，所以 `a` 从 10 变为 11。

### 7. `break` 和 `continue` 中哪个终止本次循环

**答案：B，`continue`。**

- `continue`：跳过本轮循环剩余语句，进入下一轮判断；
- `break`：直接结束当前所在的最近一层循环或 `switch`。

在 `for` 循环中遇到 `continue` 后，通常还会执行循环变量的更新表达式，再进行条件判断。

### 8. `for` 循环累加

```c
int i, s = 0;
for (i = 1; i <= 3; i++)
    s += i;
printf("%d", s);
```

**答案：D，6。** 循环依次累加 1、2、3，结果为 `0 + 1 + 2 + 3 = 6`。

### 9. 一维数组的元素个数

**答案：B，4。**

`int arr[4]` 声明了 4 个 `int` 元素，下标范围是 `0` 到 `3`。数组容量和最后一个下标不要混淆。

### 10. `sizeof(char c[]="abc")`

**答案：C，4。**

字符串字面量 `"abc"` 实际存储为：

```text
'a'  'b'  'c'  '\\0'
```

因此数组占 4 个 `char` 的空间。`strlen(c)` 的结果是 3，而 `sizeof(c)` 的结果是 4，这是高频易错点。

### 11. `return` 语句的作用

**答案：A，返回函数值并结束函数。**

对于有返回值的函数，`return expression;` 会把结果交给调用者并立即结束当前函数。`return;` 可用于返回类型为 `void` 的函数。

### 12. 整数除法

```c
int a = 8, b = 3;
printf("%d", a / b);
```

**答案：B，2。** 两个操作数都是 `int`，执行整数除法，小数部分被舍去。若希望得到小数，需要让至少一个操作数参与浮点运算，例如 `8.0 / 3`。

### 13. 指针变量保存什么

**答案：D，内存地址。**

指针变量保存的是某个对象的地址：

```c
int x = 10;
int *p = &x;   // p 保存 x 的地址
printf("%d", *p);  // *p 取出地址对应的值，结果为 10
```

`&` 是取地址，`*` 在表达式中常表示解引用。

### 14. 数组下标

```c
int arr[] = {1, 2, 3};
printf("%d", arr[1]);
```

**答案：A，2。** C 语言数组从下标 0 开始：`arr[0]` 是 1，`arr[1]` 是 2，`arr[2]` 是 3。

### 15. 单行注释

**答案：C，`//`。** 多行注释使用 `/* ... */`。

### 16. 全局变量的定义位置

**答案：B，所有函数外部。**

在函数外定义的变量具有文件作用域，默认具有静态存储期。它可以被同一文件中的多个函数使用，但还要注意声明位置和作用域。

### 17. 复合赋值

```c
int x = 5;
x += 2;
```

**答案：D，7。** `x += 2` 等价于 `x = x + 2`。

### 18. `while` 条件为假时

**答案：A，不执行。** `while` 是入口条件循环，执行循环体前先判断条件；第一次判断为假时，循环体一次也不执行。需要“至少执行一次”时，应考虑 `do...while`。

### 19. 浮点类型关键字

基础题通常希望选择 `float`，但 `double` 也属于浮点类型。见上面的“题目歧义”说明。面试时建议说明精度差异，而不是只报一个字母。

### 20. `return 0` 的含义

**答案：B，程序正常结束。** 从 `main` 返回 0 是向操作系统报告成功结束；非 0 返回值通常用于表示异常或错误，但具体约定取决于程序。

## 四、简答题参考答案

### 1. `break` 和 `continue` 的区别

`break` 用于立即结束最近的一层 `for`、`while`、`do...while` 循环，也可以结束 `switch`；程序会跳到循环或 `switch` 后面的语句继续执行。

`continue` 只结束本轮循环，跳过本轮剩余代码，继续进行下一轮循环判断。它只能用于循环，不能单独用于 `switch`。在 `for` 中，执行 `continue` 后还会先执行更新表达式。

**一句话背记：** `break` 是“退出整个循环”，`continue` 是“跳过这一轮”。

### 2. 常量和变量的区别

常量是在程序运行过程中值不能被修改的数据；变量是有名字、可在规定作用域内存储并改变值的数据。例如：

```c
const int max_count = 10;  // 常量
int count = 0;              // 变量
count = count + 1;
```

常量强调“值不可变”，变量强调“值可以变”。`const` 能限制通过该标识符修改对象，但涉及指针时仍要区分“指针本身是否可变”和“指向的数据是否可变”。

## 五、编程题参考实现

### 1. 输出 1 到 50 之间所有奇数

```c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 50; i += 2) {
        printf("%d ", i);
    }
    putchar('\\n');
    return 0;
}
```

**思路：** 从 1 开始，每次加 2，直接得到 `1、3、5 ... 49`。也可以遍历 1 到 50，再用 `i % 2 != 0` 判断。

### 2. 使用临时变量交换两个整数

```c
#include <stdio.h>

int main(void)
{
    int a, b, temp;

    scanf("%d%d", &a, &b);
    temp = a;
    a = b;
    b = temp;

    printf("a=%d, b=%d\\n", a, b);
    return 0;
}
```

**关键点：** `scanf` 修改变量，需要传入变量地址，所以使用 `&a` 和 `&b`；临时变量用于暂存原来的 `a`，避免赋值覆盖数据。

### 3. 自定义函数求两个整数的最大值

```c
#include <stdio.h>

int max(int a, int b)
{
    return a > b ? a : b;
}

int main(void)
{
    int x = 8, y = 12;
    printf("max=%d\\n", max(x, y));
    return 0;
}
```

**关键点：** 函数声明中的返回类型、函数名、参数类型要明确；调用函数时传入实参；函数通过 `return` 把最大值返回给调用者。

## 六、核心知识点总结

### 1. 标识符与数据类型

- 标识符：字母、数字、下划线组成，不能以数字开头，不能使用关键字，C 语言区分大小写。
- 整型：`char`、`short`、`int`、`long` 等。
- 浮点型：`float`、`double`。
- C 语言没有内置 `string` 类型；字符串用 `char` 数组表示，并以 `\\0` 结束。

### 2. 运算符

| 类别 | 常见运算符 | 注意 |
| --- | --- | --- |
| 算术 | `+ - * / %` | 整数相除会丢弃小数部分 |
| 自增自减 | `++ --` | 前置、后置在复杂表达式中含义不同 |
| 关系 | `> < >= <= == !=` | `==` 是比较，`=` 是赋值 |
| 逻辑 | `&& \|\| !` | C 中 0 为假，非 0 为真 |
| 复合赋值 | `+= -= *= /= %=` | 如 `x += 2` 等价于 `x = x + 2` |

### 3. 流程控制

- `if`：根据条件分支；条件为 0 假，非 0 真。
- `for`：初始化、条件判断、循环体、更新，按这个顺序反复执行。
- `while`：先判断条件，可能一次也不执行。
- `do...while`：先执行一次循环体，再判断条件。
- `break`：退出最近一层循环或 `switch`。
- `continue`：跳过本轮循环剩余部分。
- `return`：结束当前函数，必要时返回一个值。

### 4. 数组与字符串

- 数组下标从 0 开始。
- `int arr[4]` 有 4 个元素，合法下标是 `0` 到 `3`。
- 二维数组 `a[行][列]`，例如 `int a[2][3]` 是 2 行 3 列。
- `sizeof(数组)` 求整个数组占用的字节数；数组作为函数参数时通常会退化为指针。
- `strlen` 统计字符串长度，不包含 `\\0`；字符数组初始化为字符串时，空间通常要包含 `\\0`。

### 5. 指针

- 指针变量保存地址。
- `&x`：取变量 `x` 的地址。
- `*p`：访问指针 `p` 指向的对象。
- 指针类型影响解引用时读取的字节数和指针运算步长。
- 使用指针前要确认它指向有效对象；不要解引用空指针、野指针或已经失效的地址。

### 6. 函数与程序入口

- 函数由返回类型、函数名、参数列表和函数体组成。
- 函数参数默认是值传递；需要修改调用者变量时，通常传入地址并使用指针。
- `main` 是程序入口函数。
- `return 0` 是 `main` 正常结束的常见约定。

## 七、易错点与面试注意事项

1. **真值不是只有 1。** `if (-1)`、`if (100)` 都会进入分支，只有 0 表示假。
2. **整数除法不会自动保留小数。** `8 / 3` 是 2；想得到小数要使用浮点操作数。
3. **数组下标从 0 开始。** 长度为 4 的数组最后一个元素是 `arr[3]`，访问 `arr[4]` 越界。
4. **`sizeof` 和 `strlen` 不同。** 前者看对象占用空间，后者看字符串中 `\\0` 之前的字符数。
5. **`break` 不等于结束程序。** 它只退出最近一层循环或 `switch`；结束函数要用 `return`，结束进程还涉及 `exit` 等机制。
6. **`continue` 在 `for` 中会走更新表达式。** 设计循环时要保证循环变量仍能变化，否则可能死循环。
7. **`=` 和 `==` 不要混淆。** 前者赋值，后者比较；面试解释代码时要说清楚。
8. **指针题先分清“地址”和“地址中的值”。** `p` 是地址，`*p` 是该地址处的值，`&x` 是变量 `x` 的地址。
9. **浮点类型题要看问法。** `float` 和 `double` 都是浮点类型，单精度/双精度才是区分点。
10. **编程题先写清边界。** 1 到 50 的奇数应输出到 49；循环条件是 `i <= 50`，步长为 2。

## 八、考前速记口诀

> `main` 是入口，0 假非 0 真；数组从 0 起，字符串多一个 `\\0`；整数相除取整数，指针保存地址；`break` 出循环，`continue` 跳本轮，`return` 结束函数。
