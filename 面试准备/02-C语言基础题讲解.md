## 二、选择题逐题讲解

### 1. C 语言属于什么语言

**答案：B，高级语言。**

C 语言比机器语言和汇编语言更接近人的表达方式，具有较好的可读性和可移植性，因此归为高级语言；同时它又允许直接操作内存、位和硬件接口，所以常被用于系统与嵌入式开发。

**面试表达：** C 是高级程序设计语言，但它保留了接近硬件的能力，兼顾效率与可控性。

### 2. 合法的整型常量

**答案：A，`123`。**

- `123`：十进制整型常量；
- `12.3`：带小数点，是浮点常量；
- `0xG`：十六进制数字只能使用 0-9、A-F 或 a-f，`G` 非法；
- `12u+`：`u` 可作无符号后缀，但后面的 `+` 使它不再是一个完整常量。

### 3. `char ch='A'; printf("%c", ch+1);` 输出什么

**答案：B，`B`。**

字符在内存中以编码值保存。常用字符集里 `'B'` 的编码紧接在 `'A'` 之后，所以 `'A' + 1` 的结果再用 `%c` 输出时是 `B`。

```c
char ch = 'A';
printf("%c\n", ch + 1);  // B
```

**注意：** 这里使用 `%c` 输出字符；若使用 `%d`，会输出对应的整数编码值。

### 4. 无符号整型关键字

**答案：D，`unsigned`。**

`unsigned` 表示整数不保存负数位，从而把同样的位数更多地用于表示非负数。例如：

```c
unsigned int count = 10;
```

`signed` 表示有符号，`short`、`long` 用于调整整数宽度，它们都不是“无符号”的含义。

### 5. `while` 循环结果

```c
int s = 0;
while (s < 3)
    s++;
printf("%d", s);
```

**答案：B，3。**

当 `s` 依次为 0、1、2 时，条件成立并自增；自增到 3 后，`s < 3` 不成立，循环停止。

### 6. 数组下标的起始值

**答案：A，0。**

数组第一个元素是 `arr[0]`。若 `int arr[4];`，合法下标是 `0、1、2、3`；`arr[4]` 已越界。

### 7. 运算符优先级

```c
int a = 2, b = 3;
printf("%d", a * b + a);
```

**答案：B，8。**

先算乘法：`2 * 3 = 6`；再算加法：`6 + 2 = 8`。乘除模的优先级高于加减。

### 8. `switch` 分支的结束

**答案：C，`break`。**

`switch` 中的 `break` 用于跳出整个 `switch`。如果省略它，程序可能继续执行后续 `case`，这称为“贯穿（fall-through）”。

```c
switch (choice) {
case 1:
    puts("one");
    break;
default:
    puts("other");
}
```

### 9. `for` 中的 `break`

```c
for (int i = 0; i < 4; i++) {
    if (i == 2)
        break;
    printf("%d", i);
}
```

**答案：A，`01`。**

`i = 0`、`i = 1` 时先输出；当 `i = 2` 时执行 `break`，所以 2 不会输出，循环也立即结束。

### 10. 字符型数据占用的字节数

**答案：B，1。**

C 语言规定 `sizeof(char) == 1`。这里的“1 字节”是 C 的最小可寻址存储单位；常见平台上通常为 8 位。

### 11. `strlen("hello")` 的结果

**答案：C，5。**

`strlen` 统计字符串中 `'\\0'` 之前的字符数；`"hello"` 有 5 个可见字符，结尾的空字符不计入长度。

```c
char str[] = "hello";
printf("%zu\n", strlen(str));  // 5
```

**对比：** `sizeof(str)` 通常为 6，因为还包含一个 `'\\0'`。

### 12. 实参和形参的传递方式

**答案：D，值传递（普通变量）。**

C 语言函数参数本质上是值传递：调用时，实参的值被复制给形参。即便传入的是地址，传递的也仍是“地址这个值”；通过该地址才能修改调用者的对象。

```c
void change(int x) { x = 10; }          // 不改变调用者变量
void change_by_ptr(int *p) { *p = 10; } // 可改变 p 指向的变量
```

### 13. 判断奇偶数

```c
int x = 6;
if (x % 2 == 0)
    printf("偶数");
else
    printf("奇数");
```

**答案：A，偶数。** 偶数除以 2 的余数是 0。

### 14. `double` 占用的字节数

**答案：C，8。**

在常见的现代实现中，`double` 占 8 字节；不过 C 标准并不强制所有平台必须如此。写可移植程序时，可以用 `sizeof(double)` 获取当前平台的实际大小。

### 15. 预处理指令的起始符号

**答案：B，`#`。**

预处理在编译前进行，典型指令有：

```c
#include <stdio.h>
#define MAX 100
#if defined(DEBUG)
```

`//` 和 `/* ... */` 是注释，不是预处理指令。

### 16. `do...while` 循环结果

```c
int a = 0;
do {
    a++;
} while (a > 5);
printf("%d", a);
```

**答案：D，1。**

`do...while` 会先执行循环体，再判断条件。因此即使 `a > 5` 一开始不成立，也已经执行过一次 `a++`，结果为 1。

### 17. 字符串常量的结束标志

**答案：A，`'\\0'`。**

`'\\0'` 是数值为 0 的空字符，用于标记 C 风格字符串的结束；它不是换行 `'\\n'`，也不是空格 `' '`。

### 18. 算术运算符优先级

**答案：C，`*`。**

在本题给出的选项中，乘法 `*` 高于加法 `+` 与减法 `-`。选项中的 `=` 是赋值运算符，不属于算术运算符。

### 19. 阶乘式累乘

```c
int s = 1;
for (int i = 1; i <= 4; i++)
    s *= i;
printf("%d", s);
```

**答案：B，24。** 计算过程是 `1 × 1 × 2 × 3 × 4 = 24`，也就是 `4!`。

### 20. C 语言常用输出函数

**答案：D，`printf`。**

- `printf`：格式化输出；
- `putchar`：输出一个字符；
- `scanf`：格式化输入；
- `getchar`：读取一个字符。

| --- | --- | --- |
| 1. `int a=9; a/=2;` 后的值 | `4` | 两个操作数均为整数，`9 / 2` 舍去小数部分 |

## 四、简答题参考答案

### 1. `while` 和 `do...while` 循环的区别

`while` 是先判断、后执行的循环：当条件第一次就不成立时，循环体可以一次也不执行。

`do...while` 是先执行、后判断的循环：无论条件是否成立，循环体至少会执行一次。

```c
while (condition) {
    /* 条件为假时，可能不执行 */
}

do {
    /* 至少执行一次 */
} while (condition);
```

**一句话背记：** `while` “先问再做”，`do...while` “先做再问”。

### 2. 数组的特点

数组是**一组相同类型、连续存储**的数据，使用同一个数组名和下标访问各个元素。

- 元素类型相同；
- 在内存中通常连续排列；
- 元素个数在定义数组时确定，普通数组长度不能在运行中改变；
- 下标从 0 开始；
- C 语言不会自动检查数组是否越界，因此访问时必须保证下标合法。

## 五、编程题参考实现

### 1. 计算 1 到 10 的累加和

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;

    for (int i = 1; i <= 10; i++) {
        sum += i;
    }

    printf("sum = %d\n", sum);
    return 0;
}
```

**结果：** `55`。循环解法通用；若题目明确只求 1 到 10，也可用公式 `10 * 11 / 2`。

### 2. 判断一个整数是否为正数

```c
#include <stdio.h>

int main(void)
{
    int n;

    scanf("%d", &n);
    if (n > 0) {
        printf("正数\n");
    } else if (n == 0) {
        printf("零\n");
    } else {
        printf("负数\n");
    }

    return 0;
}
```

**关键点：** 0 既不是正数也不是负数，所以要单独处理。

### 3. 遍历输出一维数组所有元素

```c
#include <stdio.h>

int main(void)
{
    int arr[] = {3, 5, 7, 9, 11};
    int count = (int)(sizeof(arr) / sizeof(arr[0]));

    for (int i = 0; i < count; i++) {
        printf("%d ", arr[i]);
    }
    putchar('\n');

    return 0;
}
```

**关键点：** 在数组定义所在的作用域里，可通过 `sizeof(arr) / sizeof(arr[0])` 得到元素个数；数组作为函数参数传递后通常会退化为指针，不能再用同样方法求长度。

## 六、核心知识点总结

### 1. 整数、字符与表达式

- 整型常量可以是十进制、八进制或十六进制形式，必须符合各进制的数字规则。
- `char` 可以参与整数运算，输出时按 `%c` 显示字符、按 `%d` 显示整数值。
- `unsigned` 表示无符号整数；不要把无符号数与负数混合比较。
- 乘、除、模的优先级高于加、减；不确定时用括号明确顺序。

### 2. 循环与分支

- `while`：先判断条件，可能执行 0 次。
- `do...while`：先执行循环体，至少执行 1 次。
- `for`：适合循环次数清晰的场景，执行顺序为初始化 → 条件 → 循环体 → 更新。
- `break`：退出最近一层循环或 `switch`。
- `switch` 分支通常用 `break` 防止无意贯穿。
- 奇偶判断常用 `x % 2 == 0`。

### 3. 字符串与输入输出

| 项目 | 作用 | 典型易错点 |
| --- | --- | --- |
| `printf` | 格式化输出 | `%d` 输出整数，`%c` 输出字符 |
| `scanf` | 格式化输入 | 普通变量前通常要加 `&` 传地址 |
| `putchar` | 输出单个字符 | 不能替代格式化输出 |
| `getchar` | 读取单个字符 | 读取后注意缓冲区中的换行 |
| `strlen` | 统计字符串长度 | 不计算末尾 `'\\0'` |

### 4. 数组与函数参数

- 数组元素类型相同、存储连续、下标从 0 开始。
- 数组初始化时，未指定的整型元素会补 0。
- 普通函数参数采用值传递，函数内修改形参不影响实参。
- 若希望在函数中修改调用者变量，应传入变量地址，并通过指针解引用修改。

### 5. 预处理与类型大小

- `#include`、`#define` 等以 `#` 开始，在正式编译前由预处理器处理。
- `sizeof(char)` 恒为 1。
- `sizeof(double)` 常见为 8，但具体大小应以当前平台的 `sizeof` 结果为准。

## 七、易错点与面试注意事项

1. **字符不是字符串。** `'A'` 是单个字符常量，`"A"` 是包含 `A` 和 `'\\0'` 的字符串常量。
2. **`strlen` 不包含结尾空字符。** 但字符数组的 `sizeof` 往往会包含它。
3. **`do...while` 末尾有分号。** 写法必须是 `while (condition);`。
4. **`break` 只跳出最近一层结构。** 嵌套循环中，它不会自动跳出所有外层循环。
5. **整数除法会截断。** `9 / 2` 是 4；要得到 4.5，至少一个操作数应为浮点数。
6. **数组不要越界。** C 语言通常不会报错，但越界属于未定义行为，可能导致程序异常。
7. **局部数组未初始化时不能假定为 0。** “默认补 0”仅发生在初始化器提供了部分初始值时，或对象具有静态存储期时。
8. **所有参数仍是值传递。** “传指针”只是把地址值复制给形参；借助地址才能间接改到外部数据。
9. **类型大小与平台有关。** `char` 是 1 字节是语言保证；其他类型的实际字节数不要脱离平台盲背。

## 八、考前速记

> C 是高级语言；字符能运算，输出要配格式。数组从 0 起，字符串以 `'\\0'` 止；`while` 先判断，`do...while` 至少一次；普通参数传值，想改外部就传地址；预处理先见 `#`，数组补零只在初始化。
