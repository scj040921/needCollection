## 二、选择题逐题讲解

### 1. 不属于循环结构的是哪个

**答案：C，`if`。**

`for`、`while`、`do...while` 都可以重复执行循环体；`if` 仅根据条件选择是否执行某个分支，本身不具备重复机制。

### 2. 后置自增的执行顺序

```c
int a = 3, b = 5;
a = b++;
printf("%d,%d", a, b);
```

**答案：B，`5,6`。**

后置自增 `b++` 的结果是递增前的旧值 5，先把 5 赋给 `a`，再把 `b` 增加为 6。

**对比：**

```c
a = ++b;  // 先把 b 增为 6，再赋给 a，因此 a=6、b=6
```

### 3. 宏定义的作用

**答案：A，代码中的 `N` 在预处理阶段被替换为 10。**

```c
#define N 10
int a[N];
```

宏不是变量，也不会分配存储空间；它是预处理器进行的文本替换。

### 4. `switch` 分支执行过程

```c
int x = 2;
switch (x) {
case 1: x++;
case 2: x += 2; break;
case 3: x *= 2;
}
printf("%d", x);
```

**答案：C，4。**

`x` 为 2，直接进入 `case 2`，执行 `x += 2` 得到 4，然后遇到 `break` 跳出 `switch`。

> [!warning] 原题排版问题
> 原文写作 `case3`，这在 C 代码中会被当作普通标识符而不是 `case 3`，语法不正确。按选项和题意，应理解为 `case 3:`；该分支在本题中不会执行，因此不影响结果。

### 5. 指针 `p++` 的含义

**答案：B，指向下一个元素。**

若 `p` 是 `int *`，`p + 1` 会移动 `sizeof(int)` 个字节，指向下一个 `int` 元素；它不是单纯的“地址加 1 字节”。

```c
int arr[] = {10, 20, 30};
int *p = arr;
p++;               // 现在 p 指向 arr[1]
printf("%d", *p);  // 20
```

### 6. 数组的部分初始化

```c
int arr[3] = {1};
printf("%d,%d", arr[1], arr[2]);
```

**答案：C，`0,0`。**

带初始化器定义数组时，未写出的整型元素会补 0，所以数组等价于 `{1, 0, 0}`。

### 7. 静态局部变量的关键字

**答案：D，`static`。**

`static` 局部变量只在第一次执行到定义处时初始化一次，后续函数调用会保留上次的值；它的作用域仍限定在函数内部。

### 8. 函数嵌套调用

```c
int fun(int n) { return n * 2; }

int main(void)
{
    int a = 3;
    printf("%d", fun(fun(a)));
}
```

**答案：A，12。** 内层 `fun(3)` 得到 6，外层 `fun(6)` 得到 12。

### 9. 字符串复制函数

**答案：B，`strcpy`。**

| 函数 | 作用 |
| --- | --- |
| `strcpy(dest, src)` | 复制字符串 |
| `strcmp(a, b)` | 比较字符串 |
| `strlen(s)` | 获取字符串长度 |
| `strcat(dest, src)` | 拼接字符串 |

**注意：** 目标数组空间必须足够，否则 `strcpy` 会造成越界。实际项目更应关注长度限制，如使用 `snprintf` 等方式控制写入范围。

### 10. `while(i-->0)` 的输出

```c
int i = 5;
while (i-- > 0)
    printf("%d", i);
```

**答案：B，`43210`。**

条件判断时先取 `i` 的旧值，再让 `i` 自减。第一次判断用 5 参与比较，条件成立后 `i` 已经变为 4，因此第一次输出 4；最后一次输出 0。

**阅读建议：** 把它写成 `while (i-- > 0)`，不要写成难读的 `i-->0`。

### 11. 结构体的内存大小

**答案：C，内存对齐规则。**

结构体成员在内存中的排布会受成员类型、编译器和平台的对齐规则影响，因此 `sizeof(struct)` 不一定等于各成员大小的简单相加。

### 12. 指针偏移访问字符

```c
char *p = "abcde";
printf("%c", *(p + 2));
```

**答案：A，`c`。**

`p` 指向第一个字符 `a`，`p + 2` 指向下标为 2 的第三个字符 `c`，解引用后得到该字符。

### 13. `extern` 的作用

**答案：B，声明外部变量。**

`extern` 用于声明在其他位置定义的变量或函数，使当前源文件可以引用它。声明不等于再次定义，通常不会分配新的存储空间。

```c
/* file_a.c */
int count = 0;

/* file_b.c */
extern int count;
```

### 14. 复合赋值

```c
int a = 10;
a -= a * 2;
printf("%d", a);
```

**答案：C，-10。** `a -= a * 2` 等价于 `a = a - a * 2`，右侧先计算 `10 * 2`，再得到 `10 - 20 = -10`。

### 15. 链表相对顺序表的优势

**答案：D，插入删除无需移动元素。**

在已经找到插入或删除位置的前提下，链表只需修改相邻结点的指针；顺序表通常需要移动后续元素。

**边界：** 链表并非“查找更快”。普通链表不支持随机访问，按下标查找往往是 `O(n)`。

### 16. `continue` 的执行效果

```c
for (int i = 0; i < 5; i++) {
    if (i % 2 == 1)
        continue;
    printf("%d", i);
}
```

**答案：B，`024`。** 当 `i` 为 1、3 时，`continue` 跳过本轮的 `printf`；偶数 0、2、4 正常输出。

### 17. `malloc` 所需头文件

**答案：A，`stdlib.h`。**

```c
#include <stdlib.h>

int *p = malloc(10 * sizeof *p);
if (p == NULL) {
    /* 分配失败处理 */
}
/* 使用 p */
free(p);
```

**面试要点：** `malloc` 返回 `void *`，C 中可隐式转换为对象指针；分配后要判断是否为 `NULL`；最后使用 `free` 释放。

### 18. 条件运算符

```c
int a, b = 2;
a = b > 1 ? 5 : 3;
printf("%d", a);
```

**答案：D，5。** 条件 `b > 1` 为真，因此三目表达式选择冒号前的值 5。

### 19. 共用体的特点

**答案：C，成员共享同一块内存。**

`union` 的所有成员从同一块存储空间开始放置，整体大小通常至少能容纳最大成员并满足对齐要求。同一时刻应按当前写入的成员类型来读取，否则结果可能不可移植或难以预测。

### 20. 正确的函数定义

原题的 A 与 B 都可构成合法 C 函数定义：

```c
void fun() {}                    // 合法，但空参数表不表示严格“无参数”
int fun2(int a) { return a; }    // 合法，参数类型明确
```

因此这道单选题有歧义。若考试希望选择“现代且完整表达参数类型”的写法，通常意图是 **B**。更推荐在 C 中明确写成 `void fun(void) {}` 来表达“无参数”。

## 四、简答题参考答案

### 1. 指针变量的作用

指针变量用于保存对象的内存地址。通过指针可以间接访问或修改所指对象，常见用途包括：

- 向函数传入地址，使函数能够修改调用者的数据；
- 遍历数组和字符串；
- 动态申请与释放内存；
- 构建链表、树等动态数据结构；
- 在底层开发中访问硬件寄存器或内存映射区域。

使用指针时必须保证它指向有效对象，不能随意解引用空指针、未初始化指针、悬空指针。

### 2. 宏定义和函数的区别

宏定义由预处理器在编译前进行文本替换；函数则由编译器处理，在运行时通过调用执行。

| 对比项 | 宏 | 函数 |
| --- | --- | --- |
| 处理阶段 | 预处理阶段 | 编译后参与运行 |
| 类型检查 | 通常没有 | 有参数和返回值类型检查 |
| 参数求值 | 可能重复求值 | 实参通常只求值一次 |
| 调试 | 展开后不易调试 | 更容易单步调试 |
| 开销 | 没有常规调用开销 | 可能有调用开销，编译器也可能内联 |

宏应给参数和整体表达式加括号，避免优先级错误：

```c
#define SQUARE(x) ((x) * (x))
```

即使如此，也不要把带副作用的表达式传给宏，例如 `SQUARE(i++)`，因为 `i++` 可能执行两次。

## 五、编程题参考实现

### 1. 冒泡排序实现数组升序排序

```c
#include <stdio.h>

void bubble_sort(int arr[], int count)
{
    for (int end = count - 1; end > 0; end--) {
        int swapped = 0;

        for (int i = 0; i < end; i++) {
            if (arr[i] > arr[i + 1]) {
                int temp = arr[i];
                arr[i] = arr[i + 1];
                arr[i + 1] = temp;
                swapped = 1;
            }
        }

        if (!swapped) {
            break;
        }
    }
}

int main(void)
{
    int arr[] = {5, 1, 4, 2, 8};
    int count = (int)(sizeof arr / sizeof arr[0]);

    bubble_sort(arr, count);
    for (int i = 0; i < count; i++) {
        printf("%d ", arr[i]);
    }
    putchar('\n');
    return 0;
}
```

**思路：** 每一趟把当前未排序区间最大的元素“冒”到末尾。最坏时间复杂度是 `O(n²)`，适合学习和小规模数据。

### 2. 统计字符串中大写字母个数

```c
#include <ctype.h>
#include <stdio.h>

int count_uppercase(const char *str)
{
    int count = 0;

    for (int i = 0; str[i] != '\0'; i++) {
        if (isupper((unsigned char)str[i])) {
            count++;
        }
    }
    return count;
}

int main(void)
{
    const char *text = "Hello C Language 2026!";
    printf("%d\n", count_uppercase(text));
    return 0;
}
```

**关键点：** `isupper` 声明在 `ctype.h`；遍历以 `'\0'` 为结束条件。转换为 `unsigned char` 后再传给字符分类函数更稳妥。

### 3. 递归函数求 `n` 的阶乘

```c
#include <stdio.h>

long long factorial(int n)
{
    if (n < 0) {
        return -1;  // 这里用 -1 表示输入不合法
    }
    if (n == 0 || n == 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main(void)
{
    int n = 5;
    printf("%lld\n", factorial(n));
    return 0;
}
```

**递归三要素：**

1. 明确函数要解决的问题：`factorial(n)`；
2. 设置终止条件：`n == 0` 或 `n == 1` 返回 1；
3. 写出递推关系：`n! = n × (n - 1)!`。

**注意：** 阶乘增长很快，`long long` 也会溢出；大输入更适合使用大整数方案或改为检查溢出。

## 六、核心知识点总结

### 1. 宏和预处理

- `#define`：宏定义，执行文本替换；
- `#include`：包含头文件；
- `#if / #ifdef / #endif`：条件编译；
- 宏没有类型检查，应为参数与结果加括号；
- 宏不应替代所有函数，复杂逻辑应优先使用函数或 `inline` 函数。

### 2. 指针、数组与动态内存

- 指针保存地址，`*p` 解引用访问对象，`&x` 获取变量地址；
- `p + 1` 按所指类型的大小移动，指向数组的下一个元素；
- 数组部分初始化时，剩余元素补 0；
- `malloc` 在堆上申请内存，声明在 `stdlib.h`，申请后要判空、使用后要 `free`；
- 字符串函数的目标缓冲区必须有足够空间。

### 3. 存储期与链接属性

- 普通局部变量：进入代码块创建，离开代码块结束；
- `static` 局部变量：作用域局部，生命周期为整个程序；
- 文件作用域的 `static`：限制为当前源文件可见；
- `extern`：声明外部定义的符号，便于跨源文件引用。

### 4. 结构体、共用体与链表

- 结构体成员拥有各自存储位置，整体大小受到内存对齐影响；
- 共用体成员共享存储空间，适合互斥表示不同类型的数据；
- 顺序表支持高效按下标访问，但中间插删通常要移动元素；
- 链表按位置访问慢，但已定位后插删只需修改链接关系。

### 5. 流程控制和表达式

- 后置自增：先使用旧值，再自增；
- `break` 退出最近一层循环或 `switch`；
- `continue` 跳过当前循环剩余语句；
- 三目运算符：`condition ? true_value : false_value`；
- 表达式中先看优先级，复杂情况用括号消除歧义。

## 七、易错点与面试注意事项

1. **不要把 `p++` 理解成地址加 1 字节。** 步长取决于 `p` 的类型。
2. **后置自增要先取值、再变化。** 手算时建议拆成两步，避免混淆 `i++` 与 `++i`。
3. **宏不是常量也不是函数。** 它是编译前的文本替换，注意重复求值和优先级。
4. **`void fun()` 与 `void fun(void)` 不同。** 前者不指定参数信息，后者才明确无参数。
5. **结构体大小不能只把成员大小相加。** 要考虑对齐与填充字节。
6. **`strcpy` 与 `strcat` 不会检查目标空间。** 使用前必须保证缓冲区容量足够。
7. **`malloc` 成功后还要 `free`。** 同时避免重复释放和释放后继续使用。
8. **链表插删的前提是已找到位置。** 它并不擅长随机访问。
9. **递归必须有终止条件。** 否则会无限调用，最终栈溢出。
10. **题目本身也可能有瑕疵。** 例如本卷第 4、20 题，面试时应先说明合理假设再作答。

## 八、考前速记

> 宏先替换，函数后调用；指针加一看类型；`static` 作用域小、寿命长，`extern` 声明外部量；结构体要对齐，共用体共内存；链表插删少搬家，递归一定有出口。
