# 嵌入式 C 与 Linux 知识点背记

> [!abstract] 使用方法
> 先看每篇的 **一句话背记**，再复述“为什么”和“常见坑”。涉及系统调用时，能说清返回值、资源释放和阻塞行为。

## 六块复习路线

1. [[01-C语言与内存]]：类型、指针、数组、函数和字符串；
2. [[02-Linux基础]]：目录、权限、环境变量与常用命令；
3. [[03-文件IO与显示]]：文件描述符、标准 IO、`stat`、`mmap`、LCD/BMP；
4. [[04-数据结构]]：表、栈、队列、树与排序；
5. [[05-并发编程]]：进程、线程、信号、同步与 IPC；
6. [[06-网络编程]]：分层、字节序、UDP/TCP、socket 与 HTTP/JSON。

## 高频答题框架

1. **定义**：它是什么；
2. **机制**：内核/内存中怎样工作；
3. **取舍**：优点、缺点、适用场景；
4. **安全点**：边界、返回值、并发或资源释放；
5. **嵌入式落地**：内存有限、实时性、设备/网络异常如何处理。

> [!tip] 考前 10 分钟
> 按“C 指针 → 文件描述符 → 进程线程 → TCP 收发”串起来：数据在内存中由指针访问，经文件/套接字描述符交给内核；并发时用同步保护共享数据；网络端再按协议解析字节流。
