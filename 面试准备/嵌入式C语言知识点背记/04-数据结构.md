# 数据结构

## 线性表：先辨访问模式

| 结构 | 优势 | 代价 | 适合 |
| --- | --- | --- | --- |
| 顺序表/数组 | 下标随机访问 `O(1)`，缓存友好 | 中间插删要搬移 `O(n)`，容量受限 | 固定表、查找多 |
| 单链表 | 已知节点前驱时插删 `O(1)`，可动态增长 | 查找 `O(n)`，额外指针且缓存较差 | 插删多、节点大小不定 |
| 栈 | 后进先出，压栈/出栈 `O(1)` | 只能访问栈顶 | 函数调用、括号匹配、DFS |
| 队列 | 先进先出，入队/出队 `O(1)` | 不能随机访问 | 缓冲区、任务调度、BFS |

- 循环队列用“空一格”区分空/满：空 `front == rear`；满 `(rear + 1) % N == front`。
- 单链表删除节点前先保存 `next`；反转链表核心是维护 `prev/current/next` 三个指针。
- 链表遍历结束后必须把临时指针置空吗？不是必须；关键是不能丢失待释放链表头，也不能释放后解引用。

## 时间换空间、空间换时间

- 哈希表用额外桶/数组把平均查找降到 `O(1)`，代价是内存与碰撞处理。
- 缓存、查表、预分配常用空间换时间；压缩、流式处理常用时间换空间。
- 嵌入式优先先算上界：元素数量、每个节点大小、最坏碰撞/最坏递归深度，避免“平均情况很好”却内存耗尽。

## 二叉树与遍历

- 二叉树每个节点最多两个孩子；二叉搜索树（BST）额外满足左小右大。
- 前序：根左右；中序：左根右（BST 中序得到有序序列）；后序：左右根；层序：借助队列。
- 平衡树通过控制高度避免 BST 退化成链表；无需把所有树都背成代码，先说明为何要平衡。

## 排序与复杂度

| 算法 | 平均/最坏 | 特点 |
| --- | --- | --- |
| 冒泡 | `O(n²)` | 相邻交换，教学用 |
| 选择 | `O(n²)` | 交换较少，不稳定 |
| 插入 | 最坏 `O(n²)` | 近乎有序时快、稳定 |
| 快排 | 平均 `O(n log n)`，最坏 `O(n²)` | 原地快，选枢轴防退化 |
| 归并 | `O(n log n)` | 稳定，需额外空间 |

> [!tip] 面试表达
> 选择结构先说“访问、插入、删除各占多少”，再结合内存上限和实时性；不要只背 Big-O。
