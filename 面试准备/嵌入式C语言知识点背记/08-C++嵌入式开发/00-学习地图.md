# C++ 嵌入式开发

> [!abstract] 主线
> C++ 不等于“C 加类”。它最重要的价值是：把资源所有权、接口边界和不变量放进类型系统，让复杂程序更不容易错。

1. [[01-基础与资源管理]]：编译、引用、重载、RAII、智能指针；
2. [[02-类对象与多态]]：构造析构、拷贝移动、继承和虚函数；
3. [[03-模板STL与现代C++]]：泛型、容器、可调用对象、转发；
4. [[04-IO异常与并发]]：流、异常、类型转换、`std::thread`。

## 嵌入式取舍

可以使用 C++，但要明确编译器版本、异常/RTTI 是否启用、动态分配上限和实时路径。驱动寄存器/中断热路径追求确定性；上层协议、状态机和资源管理很适合现代 C++。
