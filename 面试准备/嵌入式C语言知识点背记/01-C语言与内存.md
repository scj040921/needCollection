# C语言与内存

## 类型、存储与作用域

| 点 | 一句话背记 | 易错点 |
| --- | --- | --- |
| 可移植性 | 用 `<stdint.h>` 的 `uint8_t/int32_t` 明确位宽；不能假设 `int` 总是 4 字节 | `sizeof` 与平台、ABI 有关 |
| `const` | 通过该名字不能改对象；`const int *p` 不能改 `*p` | `const` 不一定在只读内存，强转写入可能未定义 |
| `static` | 局部变量：生命周期贯穿程序；文件全局：仅本文件可见 | 它不是“全局变量”的同义词 |
| `volatile` | 每次读写都要真正访问内存，适合寄存器/被中断修改的标志 | **不**保证原子性和线程安全 |
| `extern` | 声明变量/函数在别的翻译单元定义 | 多个 `.c` 里不要重复定义全局变量 |

> [!tip] 一句话背记
> `static` 管生命周期或链接范围，`const` 管“能否通过此名修改”，`volatile` 管“编译器不能缓存这次访问”。

## 指针、数组与函数

- 数组名大多数表达式中退化为首元素地址，但 `sizeof(arr)`、`&arr` 例外。
- `int a[4]` 中：`a + 1` 跳过一个 `int`；`&a + 1` 跳过整个数组。
- 函数形参 `int a[]` 实际是 `int *a`，函数内 `sizeof(a)` 得到指针大小。
- 普通参数是**值传递**；要修改调用者变量，传地址并检查空指针。
- 多级指针常用于“修改指针本身”，如申请内存后把新地址写回调用者。

```c
int grow(int **pp, size_t n) {
    if (pp == NULL) return -1;
    int *p = realloc(*pp, n * sizeof **pp);
    if (p == NULL) return -1;  // 原 *pp 仍有效
    *pp = p;
    return 0;
}
```

## 字符串与格式化输入输出

- C 字符串以 `\0` 结束，`strlen` **不计**结束符；缓冲区至少要有 `strlen + 1`。
- `strcpy/strcat/gets` 不知道目标容量，嵌入式项目中避免使用；优先长度受控操作，并确保最终补零。
- `scanf("%s", buf)` 遇空白停止且可能溢出；至少写宽度：`%31s` 配合 `char buf[32]`。
- `printf` 格式与实参类型必须匹配；打印 `size_t` 用 `%zu`，指针用 `%p`。

## 结构体、位运算与预处理

- 结构体为对齐可能插入填充；按“成员从大到小”排列常可减小空间，但协议/寄存器布局要谨慎。
- 位操作用无符号数：置位 `x |= (1u << n)`；清位 `x &= ~(1u << n)`；测位 `(x >> n) & 1u`。移位量不能越界。
- 宏参数要加括号：`#define MAX(a,b) ((a) > (b) ? (a) : (b))`，但参数可能被求值两次；有副作用时改用函数/内联函数。
- `typedef` 是别名；`enum` 适合状态值；`union` 成员共用存储，读取非当前活跃成员需遵守实现与协议规则。

## 递归、回调与排错

- 递归必须有终止条件；嵌入式栈小，深度不确定时改迭代。
- 回调本质是函数指针，注册前检查非空；中断回调要短小，不做阻塞、长计算和不可重入操作。
- 野指针三源：未初始化、释放后继续用、越界写。规则：初始化为 `NULL`，`free(p)` 后 `p = NULL`，所有数组访问校验边界。

> [!question] 自测
> 为什么 `volatile` 不能替代互斥锁？答：它只约束单次访问不可被优化掉，不能让“读-改-写”成为不可分割操作。
