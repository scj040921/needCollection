# Linux 基础

## 目录与命令

| 目录 | 记忆 |
| --- | --- |
| `/` | 根目录，一切路径的起点 |
| `/dev` | 设备文件，例如串口、显示设备 |
| `/proc`、`/sys` | 内核导出的运行信息/设备模型，不是普通磁盘文件 |
| `/etc` | 系统配置 |
| `/tmp` | 临时文件，不能放关键数据 |
| `/home` | 普通用户目录 |

- `pwd` 看当前位置，`ls -l` 看详情，`cd` 切目录，`cp -r` 复制目录，`find` 查找，`tar` 打包。
- `ps` 看进程，`top` 看资源，`df -h` 看文件系统空间，`du -sh` 看目录占用，`dmesg` 看内核日志。
- 管道 `|` 把前一命令的标准输出作为后一命令标准输入；重定向 `>` 覆盖、`>>` 追加、`2>` 重定向标准错误。

## 权限与用户

`ls -l` 的 `-rwxr-x---`：首位为类型；其后每三位依次为**属主、属组、其他人**的读 `r`、写 `w`、执行 `x` 权限。

- 普通文件：`x` 表示可执行；目录：`x` 表示可进入/查找目录项，只有 `r` 不一定能访问其中指定文件。
- `chmod 640 file`：属主读写、属组只读、其他无权；`chown user:group file` 改属主和组。
- `umask` 是创建时要**去掉**的权限掩码；不要把 `777` 当常规解决方案。

> [!tip] 权限背记
> 文件的 `w` 是“改内容”；目录的 `w` 是“创建/删除目录项”；删除文件看的是**父目录**权限。

## 环境变量与启动

- `PATH` 决定查找可执行文件的目录顺序；`export NAME=value` 让子进程继承。
- `echo $NAME` 查看，`env` 列出；脚本中使用变量要加引号：`"$path"`，防止空格和通配符分词。
- Shell 是命令解释器；内核负责进程、内存、驱动和系统调用。应用不能直接随意操作硬件，通常经驱动/设备文件进入内核。

## 存储与网络服务（知道用途即可）

- 分区是磁盘的逻辑分段；文件系统在分区上组织文件。`mount` 将文件系统挂到目录树。
- NFS 常用于 Linux 之间共享目录；Samba 面向 Windows 文件共享；FTP 是传统文件传输，生产环境优先使用有加密认证的方案。
- 嵌入式排障常用顺序：`ip addr` → `ip route` → `ping 网关` → `ping IP` → DNS/端口/服务日志。

> [!question] 自测
> 为什么可执行文件放在当前目录要写 `./app`？答：当前目录通常不在 `PATH` 中，`./` 明确指定路径。
